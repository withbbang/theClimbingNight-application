# 출시 전에 채울 문안

`apps/web/content/`에 `[확인 필요: …]`로 남긴 값의 목록이다. 값을 정하면 해당 파일의 표시를 지우고 이 목록에서도 지운다.
하나라도 남아 있으면 `/release` 점검에서 배포를 멈춘다. 개수가 다르면 `grep -rn '\[확인 필요' apps/web/content` 결과가 맞다.

법률 판단이 필요한 항목은 **(법률)** 로 표시했다. 초안이므로 게시 전에 운영자가 검토한다.

## 동호회 소개 (`about.ts`)

- [ ] 동호회 소개 글
- [ ] 주로 활동하는 지역과 암장
- [ ] 벙이 열리는 주기와 분위기

## 이용약관 (`terms.ts`)

- [ ] 시행일
- [ ] 가입 가능 나이와 14세 미만 가입 처리 (법률, 방침의 같은 항목과 맞춘다)
- [ ] 게시물 권리와 이용 허락 범위 (법률)
- [ ] 임시조치 기준과 처리 기간. 구현된 값: 초상권·사생활 침해 신고 1건, 그 밖의 사유는 서로 다른 3명이 신고하면 자동 숨김, 운영진이 복원·확정 숨김 (법률)
- [ ] 이용 제한 기준과 이의 제기 방법
- [ ] 활동 중 사고 책임과 보험 (법률)
- [ ] 약관 변경 사전 공지 기간 (법률)
- [ ] 운영자 이름과 연락처

## 개인정보처리방침 (`privacy.ts`)

- [ ] 시행일
- [ ] 운영 서버와 Cloudflare의 접속 기록 항목. 정해진 값: nginx가 IP, 접속 시각, 요청 방식·경로(쿼리 제외), 응답 코드, 응답 크기, 브라우저 정보, 처리 시간을 남기고 docker 로그 회전(10MB × 3개)으로 지운다 (`deploy/nginx/default.conf`)
- [ ] 처리의 법적 근거 (법률)
- [ ] 탈퇴 뒤 남는 회원 번호, 명부, 활동 기록의 보관 기간 (법률)
- [ ] 게시물, 신고, 차단 기록의 보관 기간. 정해진 값: 게시물 삭제 시 표시용 사진은 바로, NAS 원본은 30일 뒤 지움. 신고·차단 기록은 탈퇴 뒤에도 남김 (법률)
- [ ] 백업에 남은 정보의 보관 기간. 정해진 값: DB 백업은 매일 1회, NAS에 최근 30개, R2에 30일 (`deploy/backup.sh`)
- [ ] Cloudflare 이용 범위 (접속 중계, 사진 저장(R2), 백업)
- [ ] 위탁과 국외 이전 고지: 받는 자의 연락처, 이전 국가·시기·방법, 보관 기간, 거부 방법 (법률)
- [ ] 앱 없이 계정 삭제를 요청하는 연락처와 본인 확인 방법 (스토어 심사에 필요)
- [ ] 14세 미만 가입 가능 여부와 법정대리인 동의 (법률)
- [ ] 책임자 이름과 연락처

굿즈(`goods.ts`)에는 남은 표시가 없다. 판매를 시작할 때 목록을 채운다.
